## GitHub Actions pricing (web search 2026-09-06; secondary sources, treat numbers as unverified until read on docs.github.com)
- Free plan private repositories: 2,000 included Linux minutes/month and 500 MB artifact storage. Windows minutes count 2x, macOS 10x against the allowance. Larger runners are never included. Sources: https://docs.github.com/billing/managing-billing-for-github-actions/about-billing-for-github-actions ; https://github.blog/changelog/2025-12-16-coming-soon-simpler-pricing-and-a-better-experience-for-github-actions/ ; https://resources.github.com/actions/2026-pricing-changes-for-github-actions/
- A pricing change was announced December 2025 for 2026; exact current per-minute rates were not read from the primary page in this session (unverified).
- Public repositories get unlimited standard-runner minutes; the repo is private by Andrew's decision (Q-E07), so the allowance applies.

## Godot in CI (web search 2026-09-06)
- Marketplace actions exist that install a pinned Godot 4 binary plus export templates on a runner and run `godot --headless --export-release/--export-debug`: "Action Setup Godot" (SolarLabyrinth/Action-Setup-Godot), "Godot Export" (firebelley/godot-export). Maintenance status and 4.7.2 support are unverified.
- Godot 4 uses the `--headless` flag on the standard Linux build; there is no separate server build. Source: docs-godot.txt and the marketplace README summaries.
- Official 4.7.2 export template archive: https://github.com/godotengine/godot/releases/download/4.7.2-stable/Godot_v4.7.2-stable_export_templates.tpz (link surfaced by search; download not performed). Official archive page for 4.7.x: https://godotengine.org/download/archive/4.7-stable/ and TADR-001 cites https://godotengine.org/download/archive/4.7.2-stable/
- Arch AUR carries godot-export-templates-*-bin 4.7.2 packages (aur.archlinux.org); the main `godot` package version in the Arch repos was not checked. Any install remains unauthorized for this audit.

## Third-party GDScript test frameworks (background knowledge, unverified for 4.7.2 compatibility)
- GUT (bitwes/Gut) and gdUnit4 (MikeSchulze/gdUnit4) are the two common Godot 4 unit-test frameworks; both run headless via the CLI. Plain `godot --headless --script <file.gd>` with a SceneTree/MainLoop subclass and explicit exit codes needs no dependency. Compatibility with 4.7.2 was not checked.
