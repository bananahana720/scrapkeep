### Declare Typed Dictionaries in GDScript

Source: https://docs.godotengine.org/en/4.7/tutorials/scripting/gdscript/gdscript_basics.html

Defines type constraints for dictionary keys and values using Dictionary[KeyType, ValueType] syntax. Both key and value types must be specified; use Variant for untyped elements.

```gdscript

```

### How to use static typing

Source: https://docs.godotengine.org/en/4.7/tutorials/scripting/gdscript/static_typing.html

To define the type of a variable, parameter, or constant in GDScript, append a colon followed by its type, which enforces that the variable's type remains consistent. If a colon is written without specifying a type, Godot attempts to infer the type automatically. Constants do not strictly require type hints because Godot infers them from assigned values, though explicit typing can clarify intent and is necessary for typed arrays.
