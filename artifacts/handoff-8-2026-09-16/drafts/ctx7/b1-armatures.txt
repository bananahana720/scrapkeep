### Armature Deform Parent > With Automatic Weights

Source: https://docs.blender.org/manual/en/latest/animation/armatures/skinning/parenting.html

The 'With Automatic Weights' option for Armature Deform Parenting automatically calculates vertex influence based on distance to bones, assigning weights to vertex groups. While easier to set up, this method can sometimes result in undesirable deformations for complex armatures or child objects, potentially requiring manual weight adjustments.

### Skinning > Armature Deform Parent

Source: https://docs.blender.org/manual/en/latest/animation/armatures/skinning/index.html

The Armature Deform Parent option allows you to parent a mesh to an armature, enabling skinning. This can be done in several ways, including using Empty Groups, Automatic Weights, or Envelope Weights, each offering different methods for assigning vertex influence.

### Bone ‣ Deform

Source: https://docs.blender.org/manual/en/latest/animation/armatures/bones/properties/deform.html

The Deform panel allows you to set deformation options for each bone. Toggling the checkbox off prevents a bone from deforming geometry, overriding any assigned weights and muting its influence. This also excludes the bone from automatic weight calculations when parenting a mesh to an armature using the 'Armature Deform' tool with 'With Automatic Weights'.

--------------------------------

### Editing Weight Paint

Source: https://docs.blender.org/manual/en/latest/sculpt_paint/weight_paint/editing.html

The Assign from Bone Envelopes tool applies the envelope weight of selected bones to the selected vertex group. Assign Automatic from Bone uses the same auto-weighting methods found in the Parent armature menu.
