### Main Region

Source: https://docs.blender.org/manual/en/latest/editors/nla/introduction.html

The NLA editor's Main Region displays tracks that function like layers, where higher tracks take precedence. Each track can contain strips, primarily Action Strips which are instances of actions. The special Action Track at the top holds the object's active action, where new keyframes are typically added.

--------------------------------

### NLA Editing

Source: https://docs.blender.org/manual/en/latest/editors/nla/editing/index.html

The NLA Editor provides tools for managing and manipulating animation data through tracks and strips. Key operations include adding, deleting, and moving tracks, as well as transforming, snapping, splitting, duplicating, and managing strips. Advanced strip operations include making and removing meta-strips, toggling muting, baking actions, applying and clearing scale, syncing action lengths, and making actions single-user.

--------------------------------

### NLA Editing > Strip

Source: https://docs.blender.org/manual/en/latest/editors/nla/editing/index.html

Strip operations in the NLA Editor enable detailed manipulation of animation segments. These include transforming strips (moving, scaling, rotating), snapping them to specific points, splitting them into multiple segments, duplicating them, creating linked duplicates, and deleting them. Users can also group strips into meta-strips for better organization, toggle the muting of strips to disable their animation, bake actions to simplify them, and manage scale properties.

--------------------------------

### Action Editor > Action Menu > Push Down Action

Source: https://docs.blender.org/manual/en/latest/editors/dope_sheet/modes/action.html

The "Push Down Action" operator creates a new NLA track below the current Action Track and moves the active action into it, similar to the NLA editor's functionality. This action leaves the object without an active action, making it uneditable directly in the Action Editor.

--------------------------------

### Animations > Export

Source: https://docs.blender.org/manual/en/latest/addons/scene_gltf2.html

The 'Active Actions merged' export mode ignores NLA organization and exports a single animation based on the active actions across all objects. The 'NLA Tracks' mode exports each NLA track as an independent glTF animation, useful for strip modifiers or multiple actions on a single track.
