### Modify imported scenes using EditorScenePostImport

Source: https://docs.godotengine.org/en/4.7/classes/class_editorscenepostimport.html

Set a tool script extending EditorScenePostImport as a scene's Custom Script import property. Override _post_import to receive the imported scene's root node, perform modifications, and return the modified root node.

```GDScript
@tool # Needed so it runs in editor.
extends EditorScenePostImport

# This sample changes all node names.
# Called right after the scene is imported and gets the root node.
func _post_import(scene):
	# Change all node names to "modified_[oldnodename]"
	iterate(scene)
	return scene # Remember to return the imported scene

func iterate(node):
	if node != null:
		node.name = "modified_" + node.name
		for child in node.get_children():
			iterate(child)

```

```C#
using Godot;

// This sample changes all node names.
// Called right after the scene is imported and gets the root node.
[Tool]
public partial class NodeRenamer : EditorScenePostImport
{
    public override GodotObject _PostImport(Node scene)
    {
        // Change all node names to "modified_[oldnodename]"
        Iterate(scene);
        return scene; // Remember to return the imported scene
    }

    public void Iterate(Node node)
    {
        if (node != null)
        {
            node.Name = $"modified_{node.Name}";
            foreach (Node child in node.GetChildren())
            {
                Iterate(child);
            }
        }
    }
}

```

### Object _post_import(scene: Node)

Source: https://docs.godotengine.org/en/4.7/classes/class_editorscenepostimport.html

Virtual callback invoked directly after a scene is imported. It accepts the root node of the scene and must return the modified scene root.

```APIDOC
## Object _post_import(scene: Node) virtual

### Description
Called after the scene was imported. This method must return the modified version of the scene.

### Parameters
- **scene** (`Node`) - The root node of the imported scene.

### Return Value
- **Object** - The modified version of the scene (typically the scene root node).
```

```APIDOC
## append_from_file

### Description
Takes a path to a glTF file and imports the data at that file path to the given GLTFState object through the `state` parameter.

### Signature
`Error append_from_file(path: String, state: GLTFState, flags: int = 0, base_path: String = "")`

### Parameters
- **path** (`String`) - File path to the glTF file.
- **state** (`GLTFState`) - The state object where imported data will be populated.
- **flags** (`int`, Optional, default = 0) - Import flags.
- **base_path** (`String`, Optional, default = "") - Tells append_from_file() where to find dependencies and can be empty.

### Return Value
- `Error` - Returns an Error status code.
```
