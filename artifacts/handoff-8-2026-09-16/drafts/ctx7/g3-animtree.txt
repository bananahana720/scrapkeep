### Using AnimationTree > Introduction

Source: https://docs.godotengine.org/en/4.7/tutorials/animation/animation_tree.html

While Godot's AnimationPlayer provides flexible animation capabilities across node properties, tracks, and audio, its blending functionality is limited to fixed cross-fade transition times. AnimationTree is a specialized node created to handle advanced animation transitions and complex blending.

### AnimationTree > Creating a tree

Source: https://docs.godotengine.org/en/4.7/tutorials/animation/animation_tree.html

To use an AnimationTree, you must configure a root node that evaluates sub-nodes and outputs an animation. Sub-nodes fall into three categories: Animation nodes (referencing an AnimationPlayer animation), Animation Root nodes (nested nodes for blending), and Animation Blend nodes (multi-input graph nodes). Common root nodes include AnimationNodeAnimation, AnimationNodeBlendTree, AnimationNodeBlendSpace1D, AnimationNodeBlendSpace2D, and AnimationNodeStateMachine.
