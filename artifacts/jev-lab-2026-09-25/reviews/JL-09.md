### Findings (all non-blocking)

- **N1. Whole-number grid slack differs between Godot and Node.**
  - `jev_io.gd` checks hp, `stage.time_s`/`tier`, `distance_m`, `damage` and `scrap.held` with 1e-9 slack. The kind is "whole" at `jev_io.gd:88-113`, evaluated at `:541` and `:584-588`. That follows `PROTOCOL.md:154`.
  - `protocol.mjs` uses exact `kinds.int` for the same fields (`:135`, `:142`, `:147-148`, `:162`, `:208`). [receipt] `numbers-and-quirks.log:37` shows Node rejecting `time_s` = whole+1e-12.
  - Result: Godot's writer is looser than the judge. An off-grid whole number would get through `write_state` and then fail Node's check, so the trial is marked `invalid`. It is caught, not silently accepted. It is unlikely in practice because Godot computes these values as integers.
  - It is a contradiction between the spec and Node, to be settled upstream. Until then, Godot should use exact integers so it matches the judge.
- **N2. Nothing stops the gate port drifting from `decide.mjs`.**
  - `_passes_gate` (`jev_io.gd:413-431`) matches `decide.mjs:104-128` rule by rule on schema-valid input: stomp (grounded or air jump), ram (fast or blazing), `hit_kicker` (`requires_speed_ms` absent, or speed ≥ it), `start_exit` (objective absent, or `inside_ring` not false), no rule means kept, and the push_objective fallback (`protocol.mjs:244-249`, `jev_io.gd:402-409`).
  - The two differ only on invalid states. For example, Node throws on `objective: null` or `jev: null`, and treats `requires_speed_ms: null` as ≥0; Godot returns a defined result in those cases.
  - Nothing guards against drift. `jev_io.gd` does not pin `GATE_VERSION` (`decide.mjs:26`). No fixture exercises `start_exit`, ram being dropped, stomp being dropped, or `hit_kicker` being kept.
  - Suggestion: add a `GATE_VERSION` constant to `jev_io.gd`, assert it in `tests/jev-fixtures.test.js`, and add gate fixtures upstream.
