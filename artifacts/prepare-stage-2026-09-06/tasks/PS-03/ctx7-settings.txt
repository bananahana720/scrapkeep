### Set reasoning effort level in settings.json

Source: https://code.claude.com/docs/en/settings-reference

Configures the default effort level across sessions for deeper reasoning or reduced token spend. Overridden by the --effort flag or CLAUDE_CODE_EFFORT_LEVEL environment variable.

```json
{
  "effortLevel": "xhigh"
}
```

--------------------------------

### Enable extended context for pinned model in Bash

Source: https://code.claude.com/docs/en/model-config

Appends the 1m suffix to request a 1M token context window for supported models. Claude Code automatically strips the suffix before sending the model ID to the provider.

```bash
export ANTHROPIC_DEFAULT_OPUS_MODEL='claude-opus-4-8[1m]'
```

--------------------------------

### Select 1M context models in Claude Code

Source: https://code.claude.com/docs/en/model-config

Appends the [1m] suffix to aliases or full model names to switch to a 1 million token context window. Requires plan support or usage credits depending on the model and configuration.

```text
# Use the opus[1m] or sonnet[1m] alias
/model opus[1m]
/model sonnet[1m]

# Or append [1m] to a full model name
/model claude-opus-4-8[1m]
```

### Pin models for third-party deployments

Source: https://code.claude.com/docs/en/model-config

Extended context can be enabled for pinned models by appending '[1m]' to the model ID in environment variables like ANTHROPIC_DEFAULT_OPUS_MODEL or ANTHROPIC_DEFAULT_SONNET_MODEL. Claude Code strips the '[1m]' suffix before transmitting the model ID to the cloud provider. When using model allowlists configured via MDM or managed settings, filtering matches on aliases, version prefixes, or full provider-form IDs, with any '[1m]' suffix stripped before evaluation.

--------------------------------

### Variables

Source: https://code.claude.com/docs/en/env-vars

ANTHROPIC_DEFAULT_MODEL sets the default model for new sessions in Claude Code v2.1.236 or later. ANTHROPIC_DEFAULT_OPUS_MODEL defines the model ID that the opus alias resolves to and that opusplan uses during Plan Mode. ANTHROPIC_DEFAULT_OPUS_MODEL_DESCRIPTION configures the display description for the pinned Opus model in the /model picker, defaulting to Custom Opus model or Custom Opus model (1M context) if the model ID includes the [1m] suffix without context disabled.
