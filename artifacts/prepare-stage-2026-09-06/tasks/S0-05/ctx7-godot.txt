### Export various property types in GDScript

Source: https://docs.godotengine.org/en/4.7/classes/class_%40gdscript.html

Exposes variables to the editor Inspector and serializes them to disk. Custom resources and nodes should be registered as global classes using class_name for proper Inspector support.

```gdscript
extends Node

enum Direction {LEFT, RIGHT, UP, DOWN}

# Built-in types.
@export var string = ""
@export var int_number = 5
@export var float_number: float = 5

# Enums.
@export var type: Variant.Type
@export var format: Image.Format
@export var direction: Direction

# Resources.
@export var image: Image
@export var custom_resource: CustomResource

# Nodes.
@export var node: Node
@export var custom_node: CustomNode

# Typed arrays.
@export var int_array: Array[int]
@export var direction_array: Array[Direction]
@export var image_array: Array[Image]
@export var node_array: Array[Node]

```

### Register a Custom Resource with an Icon in C#

Source: https://docs.godotengine.org/en/4.7/tutorials/scripting/c_sharp/c_sharp_global_classes.html

Combines [GlobalClass] and [Icon] attributes to register a custom Resource class with a custom editor icon. Exported fields of this type allow creating and inspecting instances in the editor.

```csharp
using Godot;

[GlobalClass, Icon("res://Stats/StatsIcon.svg")]
public partial class Stats : Resource
{
    [Export]
    public int Strength { get; set; }

    [Export]
    public int Defense { get; set; }

    [Export]
    public int Speed { get; set; }
}
```

### Define a custom Resource class in GDScript and C#

Source: https://docs.godotengine.org/en/4.7/tutorials/scripting/resources.html

Ensure custom Resource constructors provide default arguments or a parameterless constructor for proper Inspector instantiation. Register the class using `class_name` in GDScript or `[GlobalClass]` in C#.

```GDScript
class_name BotStats
extends Resource

@export var health: int
@export var sub_resource: Resource
@export var strings: PackedStringArray

# Make sure that every parameter has a default value.
# Otherwise, there will be problems with creating and editing
# your resource via the inspector.
func _init(p_health = 0, p_sub_resource = null, p_strings = []):
	health = p_health
	sub_resource = p_sub_resource
	strings = p_strings

```

```C#
// BotStats.cs
using Godot;

namespace ExampleProject
{
    [GlobalClass]
    public partial class BotStats : Resource
    {
        [Export]
        public int Health { get; set; }

        [Export]
        public Resource SubResource { get; set; }

        [Export]
        public string[] Strings { get; set; }

        // Make sure you provide a parameterless constructor.
        // In C#, a parameterless constructor is different from a
        // constructor with all default values.
        // Without a parameterless constructor, Godot will have problems
        // creating and editing your resource via the inspector.
        public BotStats() : this(0, null, null) {}

        public BotStats(int health, Resource subResource, string[] strings)
        {
            Health = health;
            SubResource = subResource;
            Strings = strings ?? System.Array.Empty<string>();
        }
    }
}

```

### Array duplicate(deep: bool = false) const

Source: https://docs.godotengine.org/en/4.7/classes/class_array.html

Creates and returns a copy of the array. Supports shallow copying by default or deep copying of nested containers.

```APIDOC
## duplicate

### Signature
`Array duplicate(deep: bool = false) const`

### Description
Returns a new copy of the array. By default, a shallow copy is returned: all nested `Array`, `Dictionary`, and `Resource` elements are shared with the original array. If `deep` is `true`, a deep copy is returned where nested arrays and dictionaries are duplicated recursively (Resource elements remain shared).

### Parameters
- **deep** (`bool`, default: `false`) - Whether to perform a deep recursive copy of nested arrays and dictionaries.

### Return Value
- `Array` - A new array instance containing the copied elements.
```

### PackedStringArray

Source: https://docs.godotengine.org/en/4.7/classes/class_packedstringarray.html

Constructs and initializes a PackedStringArray to tightly store String elements. Packed arrays are passed by reference and evaluate to false in boolean contexts when empty.

```APIDOC
## PackedStringArray

### Description
An array specifically designed to hold Strings. Packs data tightly to save memory for large array sizes. Packed arrays are faster to iterate on and modify compared to typed arrays (`Array[String]`) or untyped arrays, but offer fewer convenience methods.

### Example
```gdscript
var string_array = PackedStringArray(["hello", "world"])
var string = " ".join(string_array)
print(string) # "hello world"
```

### Usage Notes
- **Pass by Reference:** Packed arrays are passed by reference. Use `duplicate()` to create an independent copy.
- **Properties and Methods:** Built-in properties and methods return copies of packed arrays; modifying a returned array does not affect the original property value.
- **Boolean Evaluation:** Evaluates to `false` when empty, and `true` when non-empty.
```

### PackedStringArray > Description

Source: https://docs.godotengine.org/en/4.7/classes/class_packedstringarray.html

Packed arrays are always passed by reference. To obtain an independently modifiable copy, use duplicate(). However, built-in properties and methods return a copy of the packed array rather than a reference, meaning modifying the returned array will not alter the original value unless reassigned. In a boolean context, an empty packed array evaluates to false, while a non-empty one evaluates to true.

### Built-in types

Source: https://docs.godotengine.org/en/4.7/tutorials/scripting/gdscript/gdscript_basics.html

Built-in types in GDScript are stack-allocated and passed by value, creating a copy on assignment or function parameter passing. Exceptions to this are Object, Array, Dictionary, and packed arrays, which are passed by reference and shared. Arrays, dictionaries, and some objects provide a duplicate() method to create explicit copies.
