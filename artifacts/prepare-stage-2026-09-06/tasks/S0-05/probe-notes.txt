Probe notes for S0-05/S0-06 (engine 4.7.2.stable.official.ed1daf0bf, headless --script, project native/)

1. class_name across files is not resolvable in a headless --script run.
   probe_apis.gd (first version, referencing SlotTreeDefinition by class_name) failed to parse:
     SCRIPT ERROR: Parse Error: Could not find type "SlotTreeDefinition" in the current scope.
     ERROR: Failed to load script ".../probe_apis.gd" with error "Parse error".   exit=1
   Full output: probe-apis-run1.txt. Cause: no .godot/global_script_class_cache.cfg exists because the editor never scanned the project.
   Fix probed in probe-const-preload.txt: both `const SlotTreeDefinition = preload(...)` and
   `const SlotTreeDefinition: GDScript = preload(...)` compile under the warnings-as-errors keys and allow `.new()` and typed property access.

2. A `: GDScript`-typed preload constant hides static methods from the analyzer.
   First full proof_runner.gd run (with typed constants) failed to parse:
     SCRIPT ERROR: Parse Error: The method "validate()" is not present on the inferred type "GDScript" (but may be present on a subtype). (Warning treated as error.)
       at: GDScript::reload (res://proofs/tadr-003/proof_runner.gd:167)   exit=1
   Switching every preload constant to the untyped form fixed it; constant access (TreeRules.NODE_COUNT) worked in both forms.

3. Shallow Resource.duplicate() shares PackedStringArray storage with the source in 4.7.2; duplicate(true) copies it.
   probe-duplicate.txt: shallow_leaks=true deep_leaks=false replaced_leaks=false shallow_append_leaks=true whole_assign_leaks=false shallow_id_shared_after_change=false
   ctx7-godot.txt query 3 documents that packed arrays are passed by reference and that PackedStringArray.duplicate() copies; it does not state what Resource.duplicate(deep) does with packed-array properties.

4. ResourceSaver omits a property whose value equals the script default (content_revision = 0 absent from the generated text, probe-apis-run2.txt). The committed fixtures write it explicitly.

5. SceneTree.quit(3) yields process exit 3 and quit(1) yields exit 1 (probe-apis-run2.txt tail, probe-harness-exit3.txt, run-inject-fault.txt).

6. OS.get_cmdline_user_args() returns only the arguments after `--` (probe-apis-run2.txt: [] then ["--exit3"]).

7. ResourceLoader.CACHE_MODE_IGNORE == 0, CACHE_MODE_REUSE == 1; REUSE returns the same instance on a second load of the same path, IGNORE returns a distinct instance (probe-apis-run2.txt).

8. ResourceLoader.load on a missing path prints three ERROR lines and returns null; ResourceLoader.exists returns false (probe-apis-run2.txt).
