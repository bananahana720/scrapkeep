### FileAccess.open

Source: https://docs.godotengine.org/en/4.7/classes/class_fileaccess.html

Opens a file at the specified path using the provided mode flags. Returns a FileAccess instance configured for read or write operations.

```APIDOC
## FileAccess.open(path, flags)

### Description
Creates and opens a new FileAccess object to read from or write to the file at the specified path.

### Method
`static open(path, flags)`

### Parameters
- **path** (String) - Path to the file (e.g., `"user://save_game.dat"`).
- **flags** (ModeFlags) - Mode flag determining read/write permissions (e.g., `FileAccess.READ`, `FileAccess.WRITE`).

### Example (GDScript)
```gdscript
var file = FileAccess.open("user://save_game.dat", FileAccess.WRITE)
```

### Example (C#)
```csharp
using var file = FileAccess.Open("user://save_game.dat", FileAccess.ModeFlags.Write);
```
```

### Save and load text files using FileAccess

Source: https://docs.godotengine.org/en/4.7/tutorials/io/runtime_file_loading_and_saving.html

Demonstrates reading and writing text files on the filesystem. Use FileAccess.WRITE to write content and FileAccess.READ to read the file contents as text.

```gdscript
func save_file(content):
	var file = FileAccess.open("/path/to/file.txt", FileAccess.WRITE)
	file.store_string(content)

func load_file():
	var file = FileAccess.open("/path/to/file.txt", FileAccess.READ)
	var content = file.get_as_text()
	return content

```

```csharp
private void SaveFile(string content)
{
    using var file = FileAccess.Open("/Path/To/File.txt", FileAccess.ModeFlags.Write);
    file.StoreString(content);
}

private string LoadFile()
{
    using var file = FileAccess.Open("/Path/To/File.txt", FileAccess.ModeFlags.Read);
    string content = file.GetAsText();
    return content;
}

```

### Serialize and parse JSON with error handling in GDScript

Source: https://docs.godotengine.org/en/4.7/classes/class_json.html

Instantiate JSON and call parse() to retrieve structured data and access error messages or line numbers if parsing fails.

```gdscript
var data_to_send = ["a", "b", "c"]
var json_string = JSON.stringify(data_to_send)
# Save data
# ...
# Retrieve data
var json = JSON.new()
var error = json.parse(json_string)
if error == OK:
	var data_received = json.data
	if typeof(data_received) == TYPE_ARRAY:
		print(data_received) # Prints the array.
	else:
		print("Unexpected data")
else:
	print("JSON Parse Error: ", json.get_error_message(), " in ", json_string, " at line ", json.get_error_line())

```

### float to_float() const

Source: https://docs.godotengine.org/en/4.7/classes/class_string.html

Parses the string and converts it into a floating-point decimal number.

```APIDOC
### Method Signature
```gdscript
float to_float() const
```

### Description
Converts the string representing a decimal number into a float. This method stops on the first non-number character, except the first decimal point (`.`) and the exponent letter (`e`).

### Return Value
- **float**: The parsed float value.

### Example
```gdscript
var a = "12.35".to_float()  # a is 12.35
var b = "1.2.3".to_float()  # b is 1.2
var c = "12xy3".to_float()  # c is 12.0
var d = "1e3".to_float()    # d is 1000.0
var e = "Hello!".to_float() # e is 0.0
```
```

### Define typed Dictionaries in GDScript

Source: https://docs.godotengine.org/en/4.7/tutorials/scripting/gdscript/static_typing.html

Enclose key and value types in brackets separated by a comma. Note that nested typed collections like Dictionary[String, Dictionary[String, int]] are not supported.

```gdscript
var fruit_costs: Dictionary[String, int] = { "apple": 5, "orange": 10 }
var vehicles: Dictionary[String, Node] = { "car": $Car, "plane": $Plane }
var item_tiles: Dictionary[Vector2i, Item] = { Vector2i(0, 0): Item.new(), Vector2i(0, 1): Item.new() }
var dictionary_of_dictionaries: Dictionary[String, Dictionary] = { { } }
# var dicts: Dictionary[String, Dictionary[String, int]] -- disallowed

for fruit in fruit_costs:
	# `fruit` has type `String`

# The following would be errors:
fruit_costs["pear"] += vehicles
var s: String = fruit_costs["apple"]
fruit_costs["orange"] = "lots"

```
