## Integration decisions

- The new route is `/orchard.html`; the original `/` yard remains available and linked from the orchard.
- Three.js remains the runtime for this proof. An engine migration, class roster, full expedition, co-op, and permanent progression remain later work.
- Workers wrote disjoint staging copies under `/tmp/scrapkeep-first-build`. The coordinator serialized admission to the live workspace.
- The initial workspace check reported that the exposed `.git` path was not a usable Git repository. The build used file staging and admission; no repository was created to satisfy the workflow.
- Model dimensions determine damaging tool paths. Windup previews and active capsules come from the simulation. A distant Pruner toss adds announced spatial pressure while ordinary player damage stays effective.
- Shear and Brace are earned mechanisms with implemented effects. The optional following companion is a small first-build implementation, not the full proposed companion assembly system.

Earlier research-team records describe design work before build authorization. Their statements about having no implementation or session goal apply to those historical passes. They do not describe the current build.
