# Art reference boards

Approved by Andrew on 22 Oct 2026 as the shared reference for every art lane (see DECISIONS, "Reference before making"). Each set has its own index with the purpose note written before the board was generated. The eight style boards are the anchor every other set was matched to.

**Before building from a board, read its rows in [GROUNDING.md](GROUNDING.md):** each gameplay idea on every board is traced to the game, the roadmap, a conflict to avoid, or a cut.
