- The nominal orthographic views retain some illustrative depth; frame, governor mounting, hoist drum, wheel size and small fittings vary between views and sheets. The top governor projection remains schematic.
- The rear hatch is visible with the bucket lowered. Open-hatch close-ups retain a lowered-bucket background, so the required exposure only while tipped is not resolved. The tipped pose establishes the intended front pivot and ram motion, but bucket/frame clearance needs a 3D check.
- The exploded chassis reads as a structural frame more than a single smooth cast shell. Preserve the requested continuous cast body in the model.
- Palette roles are visually represented, but shaded pixels are not exact base-colour swatches and some tiny generated hex labels are malformed.
