The admitted siblings already fix that settings stay with their input and cache stays untracked (HF-01 line 72), that the present ignore and harness exclusions block production admission until TH-19's repair and proof exist (HF-01 line 61; HF-05 line 29), that a catalogue revision is one immutable catalogue and asset-manifest snapshot (HF-05 line 24), that the Import and source gate compares import results and settings with the source manifest (HF-05 line 49), that Presentation receives assets only as handles Session passes on D06 (HF-03b line 93; TH-16 RE-02), and that a concept image is no production proof (PD-01 lines 26, 63).
