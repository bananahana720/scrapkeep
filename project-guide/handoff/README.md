# Scrapkeep handoff folder

Live coordination material for the alpha. The coordinator of the claude.ai project "Scrapkeep" owns it. Every session and writer agent reads it, starting at [START-HERE.md](START-HERE.md).

| File | What it holds |
| --- | --- |
| [START-HERE.md](START-HERE.md) | What a new session reads first |
| [DECISIONS.md](DECISIONS.md) | Every ruling by Andrew. Newest wins |
| [LESSONS.md](LESSONS.md) | Ways of working that still apply |
| [ROADMAP.md](ROADMAP.md) | The one roadmap: world 1 sitting, full alpha, after the alpha |
| [STATE.md](STATE.md) | Wave state: the Wave facts table (the one place that names the live board), holds and carried reds |
| [GATE.md](GATE.md) | The promotion gate recipe: shards, bands, the tally check |
| [KNOWN-FAILING.tsv](KNOWN-FAILING.tsv) | The ledger of red tests a promotion may carry, each with a cause, an owner and a review date |
| [PLAY-FINDINGS.tsv](PLAY-FINDINGS.tsv) | The one list of open things a player would feel, each with a grade, an owner and a review date (ruling cn). A finding never holds a promotion |
| [WEEKLY.tsv](WEEKLY.tsv) | Tests the promotion gate leaves to the weekly sweep (ruling ca): parked worlds, old-map bot proofs and long tests that caught no planted fault, each with why and when it returns |
| [DEEP-SWEEP.md](DEEP-SWEEP.md) | The deep-modules sweep run after every promotion |
| [THREADS.md](THREADS.md) | The project's threads and who owns what |
| [COMMS.md](COMMS.md) | How we write to each other: the rules for every board post, receipt, brief, report and hand-off, and what a cloud session cannot see (ruling cz) |
| [DEVICES.md](DEVICES.md) | The PC's GPUs, its capture rules, and what the cloud box can't do |
| [ART-MISTAKES.md](ART-MISTAKES.md) | Append-only log of art mistakes |
| [shared/](shared/INDEX.md) | Reference files lanes rely on |
| [sitting-kit/](sitting-kit/README.md) | The playtest sitting page and its server |

The live board is the current wave's board issue; STATE.md's Wave facts table names it, and is the only page that does. `project-guide/coord/GRAPH.md` (archived in git history) was the wave 18 board.
