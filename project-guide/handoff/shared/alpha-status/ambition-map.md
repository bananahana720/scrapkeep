## Proposed new units, ranked (Pareto first)

Each brief is ready to hand to a lane. All cloud units stay in scripts/, sketches/core-loop/tools/ and tests (no src/, assets/, tools/blender, registry.d or sketches/core-loop/package.json), end in a draft PR, and go to the machine for gate and merge.

1. ANCHOR-SWAP (machine card, wave 17). Brief: swap park_recipes.gd place_anchor_field onto PR #32's 15-post kit so the 877 greybox anchor fields draw real posts. Moves "Look" and the zero-placeholder criterion; 842 of the 877 sit in wave 19 parks, so landing it in 17 de-risks wave 19. Proof: placeholder gate drops by about 877 on the candidate; smoke and park bots pass; Opus reviewer. Hand to the wave thread as a card.
2. CRASH-HARVEST (cloud). Brief: write scripts/crash-harvest.mjs that reads Godot stderr and logs from sketch:bots, redteam and export runs, groups crash, ERROR and SCRIPT ERROR lines by a stable signature (file:line + message without numbers), and writes findings in the red team's findings.json shape with severity from BUG-BAR (crash = blocker). Add a test with a fixture log. Moves "Stability" and "no open blocker". Proof: node test passes; run it over a recent red team sweep and report the groups; Opus reviewer.
3. RC-GATE (cloud). Brief: write scripts/alpha-rc.mjs and a root package.json script alpha:rc that runs, in order, placeholder gate, smoke, bots, export proofs, frametime check on a given capture, red team carry, AppImage cold launch, and prints one pass/fail table plus a markdown page. Missing inputs show as "not run", never pass. Moves every alpha criterion at wave 21. Proof: test with stubbed sub-commands; one real run in the cloud; Opus reviewer.
4. AUDIO-GATE (cloud). Brief: extend the placeholder gate (or add scripts/audio-gate.mjs it calls) to read audio: integrated loudness per music track with ffmpeg ebur128 against the MIX-CHECK target, loop seam check (sample jump at the loop point), and cue presence for every special-enemy and boss cue named in INTEGRATION.md. A missing cue counts as a placeholder (Andrew's rule, 00:45Z 17 Oct). Check ffmpeg is installed first. Moves "Sound and music". Proof: test fixtures; run on PR #12's tree; music thread reviews.
5. POWER-READ (cloud). Brief: write a headless capture tool (tools/power_read.gd + a scripts/ runner) that seeds a run, captures one scripted signature hit at depth 0 and again on a grown depth-4 build for each pilot, and records effect screen area (still_compare), knockback metres and sound layers fired; outputs a side-by-side phone page. Targets: 3x area, 2x knockback, 2x layers. Coordinate with Player effects and Knockback threads; it measures their work and does not change it. Proof: tool runs on main and reports today's baseline; Fable reviewer.
6. FEEL-PROBE (cloud). Brief: add a lab scenario that logs, per pilot and heft class, frames from harpoon press to tether visible, ram and grapple-slam knockback metres, and hit-stop ms, to runs.ndjson, with a lab-gate threshold (2 frames; slam 8 m standard foe, 3 m heavy). Report today's baseline first; thresholds that would change a recorded rule go to Andrew as a card. Use the scrapkeep-lab skill. Proof: lab gate exit; Fable reviewer.
7. PRIORITY-PROOF (cloud). Brief: lab scenario pairing a bot that targets each kill-first special against one that ignores it, 8 seeds each, logging hull lost and clear time; target 25% more hull lost when ignored. Feeds the wave 18 matchup lab. Proof: lab gate; Opus reviewer.
8. FIRST-TIMER audit (cloud). Brief: list every mechanic a run requires (roll, harpoon, grapple, slam, parts, shop, retry, Warden break, boss stagger, camp) and, for each, find where the game first teaches it on screen and where it is first required; write a tool check that fails when a required mechanic fires before its prompt. Moves "Clarity". Proof: check runs on main and lists today's misses; Opus reviewer.
