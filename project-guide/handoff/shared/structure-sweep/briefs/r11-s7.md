## The unit

This unit deletes Node scripts and script code that nothing runs. It changes no file the game loads.

**Deleting.** Andrew approved deleting what the surveys listed as having no caller (27 November 2026, ruling `es`: `git show origin/entropy/gate:project-guide/handoff/DECISIONS.md | grep 'Ruling es'`). A survey can be wrong and the tree has moved since, so prove each delete first. A caller is anything that loads, runs or imports the file or calls the name: another script, a scene or resource file, a string call (`call("name"`, `has_method("name"`, `Callable(x, "name")`, a `load(` of a path built from parts), a line in `package.json`, a workflow under `.github/`, a hook under `scripts/hooks/`, a skill under `.agents/skills/`, a shell or Python helper, or a page that tells a reader to run it. Search the whole repository, not one folder. A page or a ledger that only mentions the name in a record of past work is not a caller: leave that record as it is. Keep whatever has a caller and name the caller in your report. Files that only call each other are dead together.

**The caller search.** `scripts/no-caller.mjs` is on your base: `node scripts/no-caller.mjs <path> [<path> ...]` prints every tracked file that mentions each file given, leaves out mentions among the files given in the same call, and exits 0 for no mention, 1 for a mention and 2 when it could not search (treat 2 as a failure, never as a pass). Run it on every file before you delete it and put its output in your report. It cannot see five things, so check each of them by hand for every file you delete: a path built from parts in code, a script that scans a folder and runs what it finds, a Python package run with `python -m`, a mention inside a binary file, and a generator whose only trace is the asset it once made (never delete the only script that can regenerate a file the game ships; keep it and say so).
