## The unit

This unit has two parts, both Node code under `scripts/`. It changes no file the game loads.

**Part 1 (LEAD-51), one way to start git.** `scripts/lib/git.mjs` exports `git` and `gitOptional`. Both drop the variables git exports to a hook (`GIT_DIR`, `GIT_WORK_TREE`, `GIT_COMMON_DIR`, `GIT_INDEX_FILE`, `GIT_PREFIX`), so the `cwd` of the call decides which repository is read. A script that starts git itself keeps those variables, and inside the pre-push hook it has read the wrong repository twice in this sweep. On the base about forty files under `scripts/` and `tests/` start git with `spawnSync("git"`, `spawn("git"`, `execFileSync("git"` or a shell string: list them with `git grep -n -E 'spawn(Sync)?\(\s*"git"|execFile(Sync)?\(\s*"git"|exec(Sync)?\(\s*["`]git ' -- scripts tests .agents project-guide`.

## Mistakes earlier units made

Each of these sent a unit back from review at least once. Check your work against every one before you hand in.
1. **A check that passes when it read nothing.** A test or tool you add or change must fail when it cannot read or compare its input: a folder that does not open, an empty file list, an empty read, a pattern that does not compile, a command that exits non-zero or prints nothing. A Godot test that reads source to enforce a rule does every read through `sketches/core-loop/tests/support/source_scan.gd` (`SourceScan.matching` for the files that match, `SourceScan.captures` for what each match captured) and holds no `FileAccess`, `DirAccess` or `RegEx` of its own. 2. **A pattern narrower than the language.** A pattern for a declaration must allow `static` and an annotation on the same line: start it with `(?m)^\s*(?:static\s+|@[a-z0-9_]+(?:\([^)]*\))?\s+)*`.
3. **A forwarding copy left behind.** When you move a function or a constant, delete the old one and change its callers. Keep a one-line forwarder only for a caller outside the folders you may change, and name that caller.
4. **A test weakened in passing.** When a signature changes or gains an optional argument, read every test that calls it and confirm each still exercises what its label says.

6. **A stray file committed.** Stage files by name. Never `git add -A` or `git add .`: your checkout may hold an untracked `node_modules` link.
7. **A test filter that matched nothing or everything.** `npm run sketch:fast` refuses an argument it does not know. Each `--test` takes one pattern matched against the test file's name, and each is its own argument: `--test unit_suite_test --test boss_owners_test`.
8. **A grown list.** `scripts/sketch-lint.baseline.json` only shrinks. If it conflicts when you merge, keep the integration branch's blocks and remove only what `npm run sketch:lint` says no longer offends.
9. **Git started by hand in a script.** A Node script starts git through `scripts/lib/git.mjs`, which reads the repository of its `cwd` even inside a git hook.
