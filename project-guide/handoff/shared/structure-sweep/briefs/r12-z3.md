This unit deletes game code that nothing calls in four folders: `sketches/core-loop/src/combat/`, `src/build/`, `src/movement/` and `src/world/`, with the tests that exist only for the deleted code. It changes nothing a player meets.

A caller is anything that loads, runs or imports the file or calls the name: another script, a scene or resource file, a string call (`call("name"`, `has_method("name"`, `Callable(x, "name")`, a `load(` of a path built from parts), a line in `package.json`, a workflow under `.github/`, a hook under `scripts/hooks/`, a skill under `.agents/skills/`, a shell or Python helper, or a page that tells a reader to run it. Search the whole repository, not one folder. A page or a ledger that only mentions the name in a record of past work is not a caller: leave that record as it is. Keep whatever has a caller and name the caller in your report. Files that only call each other are dead together.

**The caller search.** `scripts/no-caller.mjs` is on your base: `node scripts/no-caller.mjs <path> [<path> ...]` prints every tracked file that mentions each file given, leaves out mentions among the files given in the same call, and exits 0 for no mention, 1 for a mention and 2 when it could not search (treat 2 as a failure, never as a pass). Run it on every file before you delete it and put its output in your report. It searches for files, not for function names: for a function, a constant or a variable, search the whole repository for the name as a word (`git grep -n -w <name>`), and also for the name inside a string (`call("name"`, `has_method("name"`, `Callable(x, "name")`, a signal connection by name, a `.tscn` or `.tres` file).
