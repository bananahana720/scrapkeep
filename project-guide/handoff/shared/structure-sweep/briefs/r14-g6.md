Each leaves the checkout and its entry in `git worktree list` behind. Give the checkout one owner that removes it on every way out, the ones a later change adds included: the smallest form is one removal that runs when the process exits (the removal is a synchronous git call, so it can run there) and that `finish` no longer has to remember.
