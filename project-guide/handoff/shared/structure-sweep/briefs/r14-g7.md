# Unit G7: every script asks the shared helper whether it is the one being run

This unit was written by the coordinating session with a codemod, not by a delegated writer, so this page records what the unit is for the reviewer. Base: `6433f2af7adcd347a1e55fb4c72f05093cf7d453` on `entropy/gate`. Branch: `entropy/g7-one-main-script-test`. It answers the row `LEAD-04` of the task pool (`project-guide/handoff/shared/structure-sweep/pool.tsv`).

## The unit

A Node script that can be both run and imported ends with a test: "am I the script being run". `scripts/lib/cli.mjs` has the one helper for it, `isMain(import.meta.url)`, which resolves links on both sides and falls back to a plain path compare when a path cannot be resolved. On the base, 34 scripts under `scripts/` did not use it. They spelled the test four ways: `path.resolve(process.argv[1]) === fileURLToPath(import.meta.url)`, which is wrong when the script is reached through a link; `realpathSync(process.argv[1]) === fileURLToPath(import.meta.url)`, which resolves one side only; the same with both sides resolved; and two private copies of a function `isMain()` (in `scripts/ci/shard-plan.mjs` and `scripts/dev-console.mjs`). A test in `scripts/lib/cli.test.mjs` forbade the first spelling only and carried a list of 40 files it did not look at.

The unit moves all 34 onto the helper and deletes the two private copies, the imports that are left unused, and the 40-entry list. It changes nothing else in those files. The guard test now compares the files under `scripts/` that read `process.argv[1]` with an exact list of three (the helper, its test, and one test that passes the text to a child process inside a string), fails when it walks 100 script files or fewer, and fails when a file reads as empty. A second test shows the search finds each spelling the repository has used.

The edit was made by a codemod, `project-guide/handoff/shared/structure-sweep/briefs/tools/codemod-is-main.py` on branch `entropy/briefs`. It is safe to rerun and a second run changes nothing.

Done looks like: no script under `scripts/` other than the three listed reads `process.argv[1]`; each changed script still runs its main code when started directly, when started through a link, and not when imported; no script's output, exit code or arguments change; and the guard fails when one script is put back as it was.

Left out on purpose, each a different owner: `server/index.js` and `tests/expedition-balance.mjs` (the preserved browser proofs), `.agents/hooks/safety-gate.mjs` (a safety hook that must not depend on `scripts/`), `project-guide/handoff/sitting-kit/serve.mjs` (a kit that is copied out of the repository) and `sketches/core-loop/tools/budget_audit.mjs`.
