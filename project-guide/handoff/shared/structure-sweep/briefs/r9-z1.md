## The unit

This unit deletes tool scripts that nothing runs. All paths are under `sketches/core-loop/` unless they start with `scripts/`. `TT-01` lists 72 scripts under `tools/` (about 15,500 lines) and five side scripts with no live caller. `TT-02` lists 13 capture scripts under `tools/` (`w12_side_*.gd` and `w12_recipe_cart_side.gd`, about 5,070 lines) that are copies of each other and that no script, test or command runs.

**Deleting.** Andrew approved deleting what the surveys listed as having no caller (27 November 2026, ruling `es`: `git show origin/entropy/records:project-guide/handoff/DECISIONS.md | grep 'Ruling es'`). A survey can be wrong and the tree has moved since, so prove each delete first. A caller is anything that loads, runs or imports the file or calls the name: another script, a scene or resource file, a string call (`call("name"`, `has_method("name"`, `Callable(x, "name")`, a `load(` of a path built from parts), a line in `package.json`, a workflow under `.github/`, a hook under `scripts/hooks/`, a skill under `.agents/skills/`, a shell or Python helper, or a page that tells a reader to run it. Search the whole repository, not one folder. A page or a ledger that only mentions the name in a record of past work is not a caller: leave that record as it is. Keep whatever has a caller and name the caller in your report. Files that only call each other are dead together.

**Part 1, the tool that proves it.** There are too many files to check by hand, and later units will delete more. Write `scripts/no-caller.mjs`: given file paths, it prints for each one every tracked file that mentions it, and exits 1 if any file given has a mention. A mention is the file's name with its folder as the game spells it (`res://tools/NAME.gd`), its path from the repository root, or its bare file name; for a `.gd` file also its `class_name`, if it declares one. Do not count the file itself, its `.uid` file, or another file given in the same call (files that only call each other are dead together). Search every tracked file with `git grep -l -F`, the whole repository. Print each mention as `path:line`, so a reader can judge it. Keep it small: one file, no options beyond the paths, and a test file `scripts/no-caller.test.mjs` that builds a scratch git repository with one called file, one dead file and two files that only call each other. Prove it on the tree first: run it on three scripts you know are live (for example `tools/test_batch_driver.gd`) and check that it finds their callers.

**Part 2, the deletes.** Run the tool on every file the two findings list. For each file with no mention, delete it with its `.uid` file (`git rm` both). For each file with a mention, read the mention: if it is a record of past work or a page that only lists the file, the file is still dead, so delete it and leave the record; if a page tells a reader to run it, or a script, test, skill, workflow or command runs it, keep the file and name the caller. If a deleted script was the only user of another file (a helper, a fixture, a scene), run the tool on that file too and delete it if it is now dead; stop there and list anything further you suspect. Put the tool's output for the deleted files in the pull request body, shortened to a count and the mentions you judged.

For every change: find every caller first, weigh at least two options, and take the one that leaves the least code and adds no new layer. If the cheapest option for one item still adds more code or indirection than the problem it removes is worth, leave that item and say so with the reason: a left item with a reason is a good result, a forced fix is not. When a new call or a new home replaces an old one, move every caller in the same commit and delete the old one; no forwarding copy stays behind. Add no code comments (the repo's rule in `CONTRIBUTING.md`, "Editing conventions"). No test may be deleted or weakened, except a test whose only subject is a file this brief has you delete. Never edit any `package.json`. One commit for each part.

Done looks like: every file `TT-01` and `TT-02` list is deleted or kept with its caller named; `node scripts/no-caller.mjs <a live script>` exits 1 and lists its callers; `npm run sketch:lint` is green with no entry added to `scripts/sketch-lint.baseline.json` (remove an entry the lint reports as `no longer offends`); nothing a player or a test can observe changes.
