**Commit A, `717d8b1f2f2eb0bfc03d619783e2536d41a80591`: "Process helper: an onChild that throws stops the child and removes the signal listeners".** Files: `scripts/lib/proc.mjs`, `scripts/lib/proc.test.mjs` and three lines of `scripts/lib/git.mjs`. Background: `runProcess` in `scripts/lib/proc.mjs` starts a child in its own process group and, when the caller sets `forwardSignals`, forwards `SIGINT` and `SIGTERM` to the group. An earlier commit moved the listeners to before `spawn`, so a signal that lands the moment the child starts still reaps the group. The review of that commit found one blocking issue: `runProcess` calls the caller's `onChild(child)` callback right after `spawn`, and when that callback threw, the two signal listeners stayed on the process and the child kept running. This commit answers it: when `onChild` throws, the helper stops the child's group, removes the listeners and rethrows.

**Commit B, `47d341b389e868d02b7916d5968cae06abb7f012`: "Shared source reader: captures() returns what each match captured".** Files: `sketches/core-loop/tests/support/source_scan.gd` and `sketches/core-loop/tests/unit/source_scan_case.gd`. Background: many Godot tests enforce a rule by reading the game's source ("only this file may declare that constant"). Several such tests were found to pass when they read nothing. `SourceScan.matching(t, roots, pattern)` is the shared reader: it returns the sorted paths of the `.gd` files under `roots` whose text matches, and it fails the test, by calling `t.check(label, false, detail)`, when the pattern does not compile, no root is given, a root does not open, a root holds no `.gd` file, or a file reads empty or with an error. This commit adds `SourceScan.captures(t, roots, pattern)`, which returns a dictionary from path to one row per match (index 0 the whole match, then the groups), and rebuilds `matching` on top of it, so a guard that needs the matched text (for example the pair "file A loads file B") no longer reads the files a second time by hand.

Read each with `git show <commit>`, and read the whole file at the commit where a check below needs it (`git show <commit>:<path>`).
