## 0. What the code actually does (the diagnosis, corrected)

Every caller steps it per tick: `chaser.gd:82`, `counter.gd:149`, `warden.gd:424-426,507`, `projectile.gd:104`, `bola_thrower.gd:76`, `miniboss.gd:195`, `perf_bench.gd:372`.

The ledger's "terrain lookup per vertex" holds only for boss hazards (`hazard.gd:119`, `boss.gd:493,826`). Consequence: every moving mark of a telegraph can be placed by a vertex shader from `centre`, `floor_y + LIFT` and a scalar; no ground profile is needed.
- Motion marks per type (`threat_grammar.gd`): INSTANT `fill` arc `inner..r_out`, `inner = lerp(r_out, r_in, p)` (`:204-205`), or two lane strips `-half..-half+p*half` and mirror (`:199-202`); LANE `run` strip `-back..-back+p*(length+back)` at ±0.9 half (`:312-313`) or arc `r_in..lerp(r_in,r_out,p)` (`:324-325`), tone RUN→LIVE alpha (`:305`); PROJECTILE `bracket` at `gap = r*lerp(1.6,0.72,p)` (`:274-276`) and `trace` dots with `s >= p` (`:283-289`); WAVE `swept` arc `r_in..front-1` (`:225`), `front` band `[max(r_in,f-1), min(r_out,f+1)]` (`:236-239`), chevrons at `f+2.6` (`:240-242`), curtain at `clamp(f, r_in, r_out)` (`:243-246`), hot alpha `lerp(0.35,0.8,p)` while arming (`:229`). - `contains()` (`telegraph.gd:139-156`) reads `radius, dir, length, width, front_radius()`; the descriptor (`:196-211`) reads the same fields. RR-01 is preserved by leaving both untouched and making the drive numbers the exact expressions above.

## 1. H1: build once, drive by instance uniform

**Built once, at commit** (`_build`, `telegraph.gd:230-243`): the static layers exactly as today, plus every motion mark at its **full extent** (progress-independent): INSTANT fill = `_footprint(d)`; LANE run = strip `-back..length` at ±0.9 half, or arc `r_in..r_out`; WAVE swept = arc `r_in..r_out`, front and front_under = the same disc (under grown by `UNDERLAY`), chevrons = 8 chevrons at unit radius, curtain = 48 spokes; PROJECTILE trace = every dot, brackets = the 8 arm segments in corner space. `set_flight()` (`:180-184`) rebuilds the trace once (it is a shape change). Nothing else rebuilds a mesh for the life of the node. Boss hazards (`hazard.gd:287-295`) keep today's path in E1: they conform to `ground`, their WAVE is a sector, and the s3 bench has none; they are E1b if the boss-peak bench shows them.

**Vertex attribute.** Painter adds `ARRAY_CUSTOM0` (`ARRAY_CUSTOM_RGBA_FLOAT << ARRAY_FORMAT_CUSTOM0_SHIFT` on `add_surface_from_arrays`) carrying per-vertex parameters a mark declares: trace dots `x = s`; chevrons `(cos a, sin a, u, v)` = ray and local offset from the tip; curtain `(cos a, sin a, h, 0)` with `h ∈ {0, reach, reach±BAND_TOP}`; brackets `(sx, sz, along, side)` plus `w = axis` (0 = x arm, 1 = z arm). Fills carry nothing: the fragment shader clips them analytically.

**Shader.** One source `src/combat/threat_mark.gdshader`, two `Shader` objects by preprocessor define (`#define STRIPES` for the stripe layers). `render_mode unshaded, cull_disabled, depth_test_disabled, blend_mix, depth_draw_never`. Start from `RenderingServer.shader_get_code(mat.get_shader_rid())` of today's stripe and plain materials (`threat_grammar.gd:730-742`) so vertex-colour sRGB handling, alpha and world triplanar stripes (`uv1_scale = 1/(0.5*sqrt 2)`) are byte-identical; add on top:

| instance uniform | meaning | set by |
| --- | --- | --- |
| `vec3 centre`, `vec2 heading` | committed centre and lane dir (constants) | once at commit |
| `int mode` | 0 pass, 1 radial clip, 2 lane clip, 3 dot threshold, 4 radial move, 5 curtain, 6 bracket | once |
| `vec4 clip` | mode 1: keep `r ∈ [x, y]`; mode 2: keep `along ∈ [x, y]` and `|lateral| ∈ [z, w]`; mode 3: keep `s >= x`; mode 4/5: `x = radius`; mode 6: `x = gap, y = arm` | per frame, `_repaint` |
| `float alpha_scale` | 1.0; WAVE hot ramp, LANE RUN→LIVE (`0.8/0.35`), swept hidden while arming (0) | per frame |
| `float governed` | 1 for P6 fills (area, fill, swept, run), 0 for everything else; read with the global below | once, from `Density.CLASS_OF_ROLE` |

Vertex(): the Painter is `top_level` with identity transform, so `world = VERTEX`; modes 4-6 replace `VERTEX.xz` from `centre`, CUSTOM0 and `clip` (chevron tip `= centre + ray*(radius) + ray*u + tangent*v`; curtain `= centre + ray*radius`, `VERTEX.y = floor + h` where `floor` is baked in the vertex; bracket `= centre + (sx*gap, sz*gap) - axis*along*arm + side*half*perp`). Fragment(): compute `r = length(world.xz - centre.xz)`, `along = dot(world.xz - centre.xz, heading)`, `lateral` from the perpendicular; `discard` outside `clip`; `ALPHA *= alpha_scale * mix(1.0, threat_fill_scale, governed)`. 16 instance uniforms is the documented limit (Godot 4.7 shading_language, per-instance uniforms); this uses 7.

**Per frame.** `_repaint()` becomes `Threat.drive(d) -> Dictionary` (role → `{clip, alpha_scale}`), pure arithmetic from the lines cited in §0, then `Painter.drive(values)` = one `set_instance_shader_parameter` per changed value on each motion instance (skip when unchanged; INSTANT at rest and a live LANE stop setting anything). Estimated ≤ 8 calls per telegraph per frame against 32 telegraphs, about 1 ms total; the ledger's H1 prize (10 ms p50) stands. `marks(d, true)` still returns the roles with their numbers (`inner`, `from/to`, `gap`, `radius/inner/outer`, `points`) merged from `drive(d)`, so `threat_grammar_test.gd:99-131,172-189` and `stress_capture.gd:408-414` keep working unchanged. `tint("fill", …)` (`telegraph.gd:251`) stays on the static `fill` StandardMaterial, gated on change. `Threat.flash` (`:770-776`) is unchanged.

**Look invariant, by construction.** Clips land on true circles where today's meshes end on 72-gons: the sagitta is `r(1-cos 2.5°) ≈ 0.001 r`, 2 cm at r = 20, sub-pixel. Straight lane cuts are identical. Brackets, chevrons and the curtain are the same segments moved by the same formulas. Fallback if a still fails its budget: rebuild that one role on the CPU per frame (brackets are 96 vertices, no ground lookups) and record the cost; never a repaint throttle (H6).

**Terrain.** Telegraphs bake nothing (flat at `center.y`, `telegraph.gd:70`). A `terrain_swap` (`world.gd:389`, `_swap` `:577-584`) does not repaint a live telegraph today either; unchanged. Hazards keep their `ground` callable on the CPU path.

## 2. Hostile-fill union on the GPU: stencil

Choice: **stencil**, per role class, in the fill shader. Godot 4.7 supports stencil in spatial shaders and on BaseMaterial3D (`stencil_mode`, `stencil_compare`, `stencil_reference`, experimental); reading the stencil buffer is supported only in the transparent pass, which is where every fill draws (`transparency = ALPHA`, `no_depth_test`, `threat_grammar.gd:733-734`). Take the exact keyword grammar from `shader_get_code` of a StandardMaterial3D with `stencil_mode = CUSTOM`, write on pass, compare NOT_EQUAL, reference bit.

- Bit 1: fill-class (INSTANT `fill`, LANE `run`, 35%); bit 2: `area` (10%, 14% projectile); bit 4: `swept` (15%). A fill of a class writes its bit and draws only where the bit is clear, so overlapping fills of one class draw exactly once: the union at 35% is inherent at any count, with no holes (the F1a `_union_footprint` holes, finding "13.0% unpainted", came from rasterising; the GPU rasterises the real triangles). Cross-class overlap is bounded at one draw per class, 1-(0.9·0.65·0.85) = 0.50 worst case, never N×0.35.
- "Past a threshold only the edges read": one **global** shader uniform `threat_fill_scale` (`RenderingServer.global_shader_parameter_add/set`, one call per frame from the governor) that the fill shader multiplies into governed fills: 1.0 below density 0.4, ramping to 0.35 at density 1.0 (fills sit at about 12% under untouched edges). CPU cost per frame: one server call, O(1), no scene walk, no mesh (F1a: 18 ms `refresh_union` at n=32 plus a fresh ArrayMesh, finding 1 and 8).
- The INSTANT closing fill keeps its timing read where fills do not overlap; inside an overlap the first-drawn wins, which is the spec's union.
- Rejected: offscreen mask (a second camera-synced viewport plus a screen quad that must sit between P5 and P1, more GPU and fragile priority); alpha clamp alone (still stacks, and thins isolated fills: the "floor-wide darkening" trade in another form). Alpha clamp is the fallback only if stencil fails the still harness under MSAA 2x (`project.godot:22`).
- Not in E1: F1a's `_union_*`, `refresh_union`, `_stable_key`, `SUPPRESSED_BY_UNION`, `cap_hostile_union` (all dropped); the escape hint (§1.3.2); DONE hazards (out of the fill path with hazards).

## 3. Kill-burst coalescing and the P5 budget

Today one kill fans out three uncoalesced visuals: `vfx.gd:118` `glyph("enemy_killed")`, `juice.gd:433-434` `burst("pop")` and `burst("debris")`, capped only by `MAX_BURSTS` per flush. One gate replaces all three: `Vfx.kill_pop(at, color, particles)` called from `juice._flush_kills()`; the `enemy_killed` connect at `vfx.gd:118` is removed. Inside: a 3-slot ring `PackedFloat64Array` of the last emitted pop times; a pop is emitted now iff `clock - ring[oldest] >= 0.25` (`Density.LEDGER.kill_pops_per_250ms`). Otherwise the kill joins the nearest pending cluster within the band's `coalesce_m` (F1a `BANDS`, reused), else a new cluster, with at most 3 pending (a fourth folds into the nearest). A cluster flushes when the ring has room and its `coalesce_ms` elapsed, emitting glyph + pop + debris once at `min(1.2^(n-1), 2.5)` (`§1.5`; F1a's `_flush_pop_cluster` formula). O(1) per kill, O(3) per frame. Tests (`tests/presentation_density_test.gd`, new file, replaces F1a's): 60 kills in 200 ms at density 0 and at 1.0 → within every 250 ms window `spawned["burst_pop"] + glyph spawns + burst_debris ≤ 3` each, cluster counts sum to 60, at least one flushed scale = 2.5. Negative control in the same test: the three raw calls with the gate bypassed give > 3, proving the counter sees the difference.

## 4. P0 to P3 exemption, consulted

`Density.CLASS_OF_ROLE` maps every mark role to a class: `area, fill, swept, run → P6`; `edge, front, chevrons, outline, bracket, pip, trace, band, band_top, owner, solid → P1`. `Painter` sets `governed` from `Density.is_shed_exempt(class)` at build, and `vfx.glyph()` takes a class argument and applies `Density.apply(class, alpha, size, life)` which returns its inputs unchanged for exempt classes; P2 `near_miss` chevrons and P3 pass `"P2"/"P3"`. Test: at density forced to 1.0 (`Governor.value = 1.0`), a `near_miss` glyph's alpha/size/life and a telegraph's `edge` and `front` instance uniforms equal the density-0 values, a P5 spark's do not. Reuse from F1a: `raw()`, `BANDS`, `SHED_ORDER`, `Governor` smoothing, `in_view`; move `_band_index`/`_shed_active` onto the `Governor` instance (finding on static state), keep `SHED_ORDER` steps that do nothing (`synergy_evolution_rings`, `drone_rack_seams`) out until an emitter exists, and drop `LEDGER` keys nothing reads.
