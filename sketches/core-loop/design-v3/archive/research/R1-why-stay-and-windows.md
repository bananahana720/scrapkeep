# R1: why stay, boss windows, layouts, class select, visual help

Haiku web scout, 2026-09-28, for the loop redesign after playtest entry 8. Evidence level: web search result summaries, not opened pages. Treat every line as a lead to check, not a verified fact.

## 1. Why a player stays in a level

- **Risk of Rain 2, teleporter charge.** Defend a zone for about 90 s while it charges; the charge rate scales with players in the dome. It is a fixed objective zone but does not hard-gate exploration, since skipping chests only costs power. https://riskofrain2.wiki.gg/wiki/Teleporter
- **Dead Cells, cursed chests.** Tier-plus loot in exchange for a curse (die in one hit until you kill N enemies): a visible risk-reward trade. https://deadcells.wiki.gg/wiki/Objects
- **Dead Cells, timed doors.** A treasure chamber opens only if the previous stages were finished within a time window. It holds money, cells and a three-choice altar. Speed and engagement both pay. https://deadcells.wiki.gg/wiki/Time,_killstreak_and_no-hit_doors
- **The Binding of Isaac, deal rooms after bosses.** A high-consequence choice whose effect you immediately see and feel. https://bindingofisaacrebirth.wiki.gg/wiki/Rooms
- **Hades, rewards shown on doors.** You see the reward type before entering, and a skull marks a harder room with a richer reward, so route choice is informed. https://game8.co/games/Hades-2/archives/453727
- **Gunfire Reborn, room rewards.** Scrolls come from room types and hidden rooms (choose one of three), so stat growth lives in room engagement. https://gunfirereborn.fandom.com/wiki/Gunfire_Reborn

## 2. Readable boss attack windows

- **Anticipation, active, recovery.** Long wind-up and long recovery, short impact. Recovery is the punish window. https://www.gamedeveloper.com/design/enemy-attacks-and-telegraphing
- **A unique telegraph per attack.** Gesture, colour and sound differ, so "this is coming, I know the answer". Clarity beats raw difficulty. https://www.gamedeveloper.com/design/opinion-boss-design---tips-from-a-combat-designer
- **Sekiro, posture.** A visible bar fills from correct defence; a break gives a deathblow window, which teaches the intended verb. https://sekiroshadowsdietwice.wiki.fextralife.com/Posture
- **The hold.** A short designed vulnerability window after a dodged attack, tuned as part of difficulty. https://buildaboss.top/en/guide/build-a-boss-beginner-guide

## 3. Layouts that invite

- **Titanfall 2.** Movement-led, larger and more open maps with several vertical combat zones; each height favours a different play. https://medium.com/@jackpbenjamin18/titanfall-2-dimensions-of-mobility-the-creation-of-the-movement-shooter-ee03c028eecd
- **Sonic.** Unbroken flow lines, several paths per skill level, environmental cues ahead of hazards at speed. https://www.gamedeveloper.com/design/sonic-3-knuckles-design-lessons-in-transition-travel-and-pantomime
- **Super Monkey Ball.** Wide curves for speed; narrowing surfaces escalate skill without breaking rhythm. https://supermonkeyball.fandom.com/wiki/Curves
- **Tony Hawk.** Transfers and reverts link geometry into combos, so the map is a combo instrument. https://strategywiki.org/wiki/Tony_Hawk's_Pro_Skater_2/Skate_Heaven
- **Hub and spoke.** Every option is visible from the hub; routes differ run to run, at the risk of feeling linear. https://soundand.design/layouts-913b8384c257
- **Marble It Up.** Optional power-ups, some safe and some risky shortcuts for speedrunners, with time-trial mastery. https://www.mygamer.com/marble-up-switch-review/

## 4. Character select that sells a class

- **Hades.** Three-choice presentation, visual type grouping, reviewable state. https://game8.co/games/Hades-2/archives/453727
- **Apex Legends.** Ability preview videos on the select screen. https://www.chenjamie.com/legend-selection
- **Deadlock.** A practice range to try abilities before committing. https://www.resetera.com/threads/deadlock-major-update-aug-18th-2025-six-new-heroes-new-personal-hub-the-hideout-and-new-character-select-screen.1273377/
- **Game UI Database.** Recurring pattern: a card plus an ability preview plus a difficulty mark. https://gameuidatabase.com/index.php?scrn=41

## 5. Help without walls of text

- **Dead Space.** Health lives on the suit's spine, readable without HUD text. https://medium.com/@lorenzoardeni/dead-space-the-ui-art-that-disappears-in-the-game-world-289718133c29
- **Diegetic versus overlay UI.** Shape and colour over text, urgency hierarchy, stable anchors. https://www.gamedeveloper.com/design/diegesis-and-designing-for-immersion
- **Visual controls in menus, and early levels that teach by consequence.** https://nerdyteachers.com/PICO-8/Game_Design/106
- **An in-world character as the tutor.** https://codechangers.com/blog/User-Interface-Elements-in-video-games-part-3-diegetic-ui/

## Scout's top 5 for a rolling-ball mech

1. Timed doors: speed-gated optional treasure (Dead Cells).
2. Reward previews before committing to a route (Hades).
3. Verticality, sightlines and multiple paths instead of a funnel (Titanfall 2, Sonic).
4. Boss attacks with long wind-up and long recovery (Sekiro, combat design talks).
5. Status shown on the mech itself, not as HUD text (Dead Space).
