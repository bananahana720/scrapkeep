# Worktree leftovers, 16 Nov 2026

Uncommitted files from old PC worktrees (waves 34 to 42), saved before those worktrees were removed. Each folder is named after the worktree's path and holds a SOURCE.txt with the worktree's commit. Most files are one-off capture scripts. `tracked-changes.patch` holds edits to tracked files. Nothing here is wired into the game; this branch is an archive, not for merging.

The 53 MB `artifacts/mojulo-lab/` folder from the mojulo plugin exploration worktree is kept as a tarball on the PC at `~/scratch/archive/mojulo-lab-2026-11-16.tar.gz`.
